# Aula 2 - Primeiro Algoritmo

**Algoritmos Computacionais** são passos a serem seguidos por um **módulo processador** e seus respectivos **usuários** que, quando executados na ordem correta, conseguem **realizar** determinada **tarefa**.

## Variáveis

**Identificadores**
1. Deve começar com uma **letra**;
2. Os próximos podem ser **letras** ou **números**;
3. **Não** pode utilizar nenhum **símbolo**, exceto _;
4. **Não** pode conter **espaços** em branco;
5. **Não** pode conter letras com **acentos**;
6. **Não** pode ser uma **palavra reservada**.

**Tipos Primitivos**
```
- Inteiro   | Ex: 1, 3, -5, 198, 0              | Não se usa aspas. 
- Real      | Ex: 0.5, 5.0, 9.8, -77.3, 3.1415  | Não se usa aspas.
- Caractere | Ex: "Gustavo", "Algoritmo", "123" | Usa-se aspas duplas.
- Logico    | Ex: Verdadeiro, Falso             | Não se usa aspas.
```

## Sintaxe Aprendida

`Escreva()` = Exibe no terminal a informação digitada dentro dos parenteses.
<br>
`Escreval()` = Exibe no terminal a informação digitada dentro dos parenteses e pula uma linha.
<br>
**Observação¹:** Para exibir uma mensagem fixa, usa-se aspas duplas.
<br>
**Observação²:** Para exibir uma variável, não é necessário aspas duplas.
<br>
**Observação³:** Para exibir uma mensagem fixa com uma variável, é necessário utilizar uma vírgula.
<br><br>
`identificador: tipo` = Método de declaração de variável.
<br>
`identificador <- valor` = Método de atribuição de valor a variável.
